# 세일즈 대시보드 사용 가이드

플렌티컨벤션 운영관리 시스템의 **세일즈 중심 대시보드** 사용법입니다.
대시보드는 로그인 후 좌측 메뉴의 **"대시보드"** 에서 확인할 수 있으며, 상단의
**MICE 세일즈 / WEDDING 세일즈** 두 섹션이 이 가이드의 대상입니다.

---

## 1. 공통 필터 (대시보드 최상단)

대시보드 맨 위의 필터바가 **두 섹션 전체에 동시 적용**됩니다.

### 기간

| 버튼 | 의미 |
|---|---|
| **오늘** | 오늘 0시 ~ 내일 0시 |
| **금주** | 이번 주 월요일 ~ 다음 주 월요일 |
| **금월** | 이번 달 1일 ~ 다음 달 1일 |
| **직접 선택** | 두 날짜를 골라서 자유 범위 지정 |

- **MICE**: 문의 통화일자(`call_date`) / 생성일시 기준
- **WEDDING**: 신규문의일자(`inquiry_date`) 기준

### 담당자

- **전체**: 모든 영업 담당자 합산
- **개별 선택**: 해당 사람이 담당한 건만 표시
- 드롭다운에는 **관리자 / 기업세일즈 / 웨딩세일즈** 역할만 노출됩니다 (연회·주방·에이치키친 제외).

---

## 2. MICE 세일즈 섹션

### 상단 KPI 카드 (5개)

모든 카드는 위에서 선택한 **기간 + 담당자 필터를 반영**합니다.

| 카드 | 설명 |
|---|---|
| **{기간} 인콜** | 해당 기간 동안 신규로 들어온 INCALL(문의 전화) 건수 |
| **{기간} 아웃콜** | 같은 기간의 OUTCALL(영업이 먼저 건 전화) 건수 |
| **미처리 인콜 (3일+)** | 단순문의 상태로 3일 이상 방치된 인콜 (누적 — 기간 무관) |
| **인콜 전환율** | 인콜 중 INQ/DEF/LOS로 전환된 비율 |
| **아웃콜 전환율** | 아웃콜 중 INQ/DEF/LOS로 전환된 비율 |

> 💡 **숫자는 클릭하면 해당 건들의 리스트가 모달로 열립니다.**
> 리스트 행을 클릭하면 해당 고객 프로필로 바로 이동.

### 퍼널 차트

- "인콜 → 전환 흐름" / "아웃콜 → 전환 흐름" 두 개
- 단계: **미처리(단순문의) → INQ → DEF → LOS**
- 각 단계 막대를 클릭하면 그 단계의 건들만 모아서 리스트로 열림

### 하단 보조 카드

- **🚨 미처리 인콜**: 3일 이상 방치된 단순문의 인콜 (상위 20건)
- **📤 최근 아웃콜**: 최근 등록된 아웃콜 10건
- **담당자별 전환율** (MICE 전체): 단순문의 외 status로 옮겨간 비율을 막대로 시각화

## 3. WEDDING 세일즈 섹션

### 상단 KPI 카드 (8개)

| 카드 | 의미 |
|---|---|
| **{기간} 신규 인콜** | 해당 기간에 들어온 신규문의 (전체 status) |
| **상담 예약** | 현재 진행단계 = `상담` 인 건 |
| **상담 취소** | 현재 진행단계 = `상담취소` 인 건 |
| **상담 전환율** | (상담 + INQ + DEF + LOS) ÷ 인콜 — 인콜 중 상담 이상 진행 비율 |
| **상담→DEF 전환율** | DEF ÷ (상담+INQ+DEF+LOS) — 상담 단계까지 도달한 건 중 최종 확정된 비율 |
| **DEF** | 확정 건수 |
| **LOS** | 잃은 건수 |
| **장기 미전환** | 14일+ `신규문의` 또는 `상담` 상태 (선택 기간 신규문의 기준) |

> 💡 **상담 전환율 vs 상담→DEF 전환율**
> - **상담 전환율**: 인콜이 상담까지 갔나? (전체 깔때기의 첫 단계 효율)
> - **상담→DEF 전환율**: 상담까지 간 건이 결국 확정됐나? (마지막 단계 효율)
> 두 값을 같이 보면 어느 구간에서 떨어지는지 파악 가능합니다.

### 퍼널 차트

- 단계: **신규문의 방치 → 상담 → 상담취소 → INQ → DEF → LOS**
- 막대 클릭 시 해당 단계 건들 리스트

### 하단 보조 카드 (모두 기간 필터 반영)

- **📅 상담 예정**: 진행단계가 `상담`이거나 희망상담일이 오늘 이후
- **❌ 상담 취소**: `상담취소` 상태
- **⏰ 장기 미전환**: 14일+ 방치된 신규문의/상담

## 4. 자주 쓰는 흐름

### "이번 주 신규 인콜이 얼마나 들어왔지?"

1. 상단 **금주** 버튼 클릭
2. WEDDING 섹션의 **금주 신규 인콜** 또는 MICE 섹션의 **금주 인콜** 숫자 확인
3. 숫자 클릭 → 어떤 업체가 들어왔는지 리스트로 확인

### "내가 담당한 건만 보고 싶어"

1. 상단 **담당자** 드롭다운에서 본인 선택
2. 모든 KPI·퍼널·리스트가 본인 담당 건으로 좁혀짐

### "이번 달 상담 효율이 어떻지?"

1. **금월** 버튼 클릭
2. **상담 전환율** (인콜 → 상담)과 **상담→DEF 전환율** (상담 → 확정) 비교
3. 상담 전환율은 높은데 DEF 전환율이 낮으면 → 상담 단계 클로징 강화 필요
4. 상담 전환율 자체가 낮으면 → 인콜 응대·후속연락 개선 필요

### "방치된 건은 없나?"

- MICE: **🚨 미처리 인콜** 카드 (3일+ 단순문의)
- WEDDING: **⏰ 장기 미전환** 카드 (14일+ 신규문의/상담)
- 누적 — 기간 필터와 무관하게 모두 보이지만 WEDDING은 기간 안에 들어온 문의 중 방치된 것만 표시

## 5. 용어 정리

### 진행단계 (MICE)

| 단계 | 의미 |
|---|---|
| **단순문의** | 처음 문의가 들어온 상태 (= 미처리) |
| **INQ** | Inquiry — 적극 문의 단계 |
| **TEN** | Tentative — 가예약 |
| **DEF** | Definite — 확정 |
| **LOS** | Lost — 잃은 건 |

### 진행단계 (WEDDING)

`신규문의 → 상담 → (INQ/TEN) → DEF / LOS`
중간에 `상담취소`로 빠질 수도 있습니다.

### 유입 채널 (MICE)

- **INCALL** 📞 — 고객이 우리에게 건 전화
- **OUTCALL** 📤 — 우리가 고객에게 건 전화 (영업)

---

## 6. 알려진 제약

- 전환 계산은 **현재 진행상태 기준**입니다 (이력을 거꾸로 거슬러 보지 않음).
  같은 건이 단순문의 → INQ → DEF로 변했다면 DEF 1건으로만 카운트됩니다.
- "장기 미전환"과 "미처리 인콜"의 기간 필터 동작이 다릅니다:
  - MICE 미처리 인콜: **누적 전체** (기간 무관)
  - WEDDING 장기 미전환: **선택 기간 안의 신규문의 중** 14일+ 방치 건

문의/오류 제보는 운영자에게 전달해주세요.
